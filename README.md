6. 向导关闭后安装器自动完成其余步骤 → 显示「✓ 部署完成」→ 启动游戏

### 重复运行 / 单项重做

### 1️⃣ 核心发现：剧本真身藏在 NTFS 隐藏流里

**问题**：替换 `Rio.arc`、`Script.arc` 等所有可见文件，游戏台词依然是英文 —— 引擎到底从哪里读剧本？

**破案**：自研文件追踪钩子（d3d9 代理内全模块 IAT 拦截，纯 Win32 API 写日志），得到 1,016 行文件访问日志 —— 排行榜第一名：

```
SysVoice.arc:sys   ← 被打开 290 次（“:sys” = NTFS 备用数据流语法！）
```

**⇒ 引擎真正读取的剧本 = `SysVoice.arc` 文件的 NTFS 备用数据流 `:sys`** —— 常规文件扫描对它完全不可见（这也是十几年汉化圈找不到它的原因）。

### 2️⃣ `:sys` 结构与 ror2 加密

```
:sys（8,787,680 B）=
  [u32 条目数 = 161][u32 条目区大小 = 5,630]
  [161 × 条目（[u32 大小][u32 偏移][UTF-16 条目名]）]
  [数据区 = ror2 加密的剧本包（8,782,042 B）]
```

数据区使用 **ror2 逐字节循环移位加密**（与 ws2 脚本同族）：

```python
def ror2(b): return ((b >> 2) | ((b << 6) & 255)) & 255   # 解密
def rol2(b): return ((b << 2) | ((b >> 6) & 255)) & 255   # 加密
```

解密后即为明文剧本：对话 = `char\0` + 正文 + NUL 结尾；说话人 = `%LC` 开头；行尾携带 `%K%P`、`\n`、`@` 等控制符。

### 3️⃣ 中文注入管线（50,990 条 · 100%）

- **同长原位注入**：中文以 GBK 写回，字节数必须 ≤ 英文原长（中文天然更短），不足以 NUL 填充 —— **绝不改变文件布局**（否则 ARC 指针全部错位）。
- **超长三级降级链**：剥引号 → 全角标点半角化 → 去行尾标点；仍超长则跳过重译。
- **覆盖率 100%**：初始词典命中 82.9%（引擎读取的是重翻译补丁**改写后**的措辞，与旧语料天然对不上）→ 缺口提取 → 6 并发批量补翻 → 多轮精修 → 手工抛光 → **50,990/50,990 全覆盖**。
- 全部校验口径：`未命中 = 0 且 超长 = 0 且 替换数 = 对话总数`。

### 4️⃣ 字体渲染优化

引擎默认使用日文明朝体（衬线）渲染中文 → 笔画细、发虚。`d3d9.dll` 代理在启动时热补丁 `gdi32` 的字体创建函数（CreateFont 四件套），将所有字体请求替换为 **微软雅黑 + GB2312 字符集** → 清晰的无衬线渲染。

> 💡 设计要点：不使用 `GetProcAddress` 内联钩（会与 Steam overlay 冲突导致 Steam 启动失败），改为直接内联挂 gdi32 源头函数 + 主模块 IAT 双保险。

### 5️⃣ 全CG / 回想解锁

游戏存档目录下的 `Save000`（775 字节）= **系统存档**（全局标志位文件，记录 CG/回想的解锁状态）。将其替换为全解锁版本即可 —— 不影响任何进度存档（`Save001`+）。

### 6️⃣ 单文件安装器（PE Overlay 架构）

**目标**：玩家只需要一个文件。全部载荷（补丁数据 1.19GB + 中文剧本流 + 字体 DLL + 存档）封装进安装器本体：

```

```

- 纯 Win32 原生 GUI（浅色主题、中文界面），运行即流式解包载荷

- 安全设计：单实例互斥、失败自动重试与清场、完整日志、部署中关窗保护

### 7️⃣ 实现铁律（血泪避坑）

1. **安装顺序**：补丁 → 中文流（**永远最后**）。补丁安装会整体重写 `SysVoice.arc`，**NTFS 文件替换会连坐删除 ADS** —— 中文流必须在其后重新注入。
2. **ADS 易失性**：任何补丁重装 / Steam 校验完整性都会删除 `:sys` —— 必须持有离机备份（本仓库 Release 的安装器内置此逻辑）。
3. **中文写回禁止空格填充**（布局敏感），必须 NUL 填充。
4. **覆盖率 = 与引擎当前读取措辞的匹配率**，不是「内容被翻译过」的存在性。
5. **差分补丁必须用原装安装器执行**（私有差分格式无法自行解析），且必须跑在干净基底上。

## ❓ 常见问题

**Q：进游戏还是英文？**
A：确认安装顺序 —— 若重装过 18+ 补丁，中文流会被连带删除，重新运行安装器勾选「中文剧本」即可。

**Q：报错 `[SysVoice.arc:sys:START]がオープンできません`？**
A：同上，中文流被删除（补丁重装/Steam 校验所致）。重新运行安装器恢复。

**Q：中英文混杂？**
A：安装器版本已内置 100% 覆盖率数据；若使用旧版本补丁请更新到最新 Release。

**Q：从 Steam 启动没反应？**
A：请使用本仓库最新版安装器（旧版字体代理与 Steam overlay 存在已知冲突，已修复）。

**Q：打了补丁后还能解锁 Steam 成就吗？**
A：**无法再解锁新成就，但已获得的成就不会丢失。**

- 原因：游戏的成就上报逻辑**只存在于 Steam 版原版引擎**中 —— 实测原版引擎导入 `steam_api.dll`，并内嵌 `SteamAPI_RunCallbacks`、`SteamUserStats` 等调用（构建标识 `VAdvHD-1.05.5-Steam`）；本补丁替换的 18+ 引擎为 MangaGamer 重编译版，**不含任何 Steam 集成代码**（导入表与字符串均无，已逐字节验证），因此补丁状态下无法向 Steam 上报成就。
- 影响范围：仅「尚未解锁」的成就；**已解锁的成就不受影响**（记录保存在 Steam 云端，不依赖本地文件）。
- 建议：在意成就收集的玩家，请**先以原版游戏完成成就，再部署本补丁**。
- 其余组件（中文剧本流 / 字体优化 / 全CG存档）与成就系统无关，不影响上述结论。

**Q：安装到一半失败了？**
A：安装器同目录会生成 `imhhw_setup_log.txt` 日志；重新运行安装器会自动跳过已完成项、重试失败项。
